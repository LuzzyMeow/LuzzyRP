# LuzzyRP 全新主题 · 设计 Spec v2（三方向硬门共同输入）

> 本文是三个方向板 subagent 的**唯一共同输入**（huashu-design Fallback Phase 3）。
> 旧「暖纸书房」方案已按用户指令整体废弃；本 spec 从零开始。

## 1. 产品是什么

LuzzyRP = 上游 RP-Hub（纯前端 Vue3 + Tailwind CDN-JIT）+ Android WebView 壳 + 独立扩展层（CSS/JS）。
本次设计目标：**一套全新应用主题**（界面配色体系 + 材质语言 + 动效性格），通过扩展层
CSS 变量覆盖实现。原版界面保留为「经典」主题选项；**新用户默认应用新主题**。

上游界面骨架（固定 DOM，主题不得改变结构，只能改：颜色、背景、描边、圆角、阴影、
字体栈引用、部分过渡动画）。可以覆盖的典型面：
顶栏黑色渐隐层、侧边栏、聊天画布、AI/用户气泡（玻璃拟态）、名字标签、输入岛、
发送按钮、强调按钮（primary 色）、边框分割线、设置页卡片与表单控件。

## 2. 用户与场景（决定性约束）

- 手机竖屏使用（WebView），大量**夜间/暗光环境长时间文字阅读**；
- 内容是沉浸式角色扮演对话：旁白 + 对白 + 用户输入，情绪浓度高；
- 用户在意的气质关键词：**沉浸、温柔、有作者感、不像"又一个 AI 工具"**；
- 明暗双模式都必须成立（默认亮色起步，暗色为夜读主力——两个模式权重同等）。

## 3. 情感基调

反「默认工具灰蓝」，反 AI slop（紫渐变/emoji 图标/圆角卡+左彩边/均匀深蓝底+霓虹 glow）。
要求：一句话就能说清气质；色彩有印刷感（低饱和、有温度或有意图的冷）；动效=物理学。

## 4. 输出格式与尺寸（硬合同，三版必须一致）

- 画布：**固定 1600 × 1200 px，单屏无滚动**的 HTML 方向板（file:// 直接打开即渲染）；
- 字体：**只用本地 `./fonts/` 的 woff2**（PuHuiTi-3 Regular/Medium/Bold、AlibabaSans
  Regular/Medium/Bold、Lora Regular）——禁止任何 CDN/在线字体/在线图片/外部请求；
- 板面内容合同（缺一不可）：
  1. 顶栏条：方向字母 + 中文方向名 + 一句气质定位 + 「逻辑来源」标签（轮盘/参照/设计师）+ 参照署名；
  2. 两台手机框（≈375×760）：**左 = 聊天界面（亮色模式），右 = 聊天界面（暗色模式）**；
     聊天屏内容用共享骨架的既定文案（凛音/雨夜便利店场景），不得改动文案与结构；
  3. 右侧信息列：色板条（gray ramp ×10 + primary/accent ramp ×10，每格标注 hex，亮暗各一组）；
  4. 字体样张：display（28px）/ 正文（15px）/ 注释（12px）三档 + 拉丁数字样张「LuzzyRP 0123456789」；
  5. 设置页预览小卡（亮+暗各一）：界面主题选择器 + 模式选择器 + 界面字体选择器 + 一个开关行；
  6. 动效令牌卡：气泡进入/退出时长与缓动、主题切换转场概念（一句话）、招牌动效（一句话）；
     基线：进入 200ms / 退出 140ms / ease-out `cubic-bezier(0.23,1,0.32,1)`，禁 scale(0)，
     尊重 prefers-reduced-motion；
  7. 「form 来自内容的哪里」一句话（五问第五问）+ 禁区自查确认行（反 slop 清单过勾）。

## 5. 共享骨架声明（对 huashu「三版互异布局」规则的修正）

huashu 要求三版布局骨架互异——那是给"从零设计的页面"的防换皮规则。本任务的**布局不是
设计变量**：主题的宿主是固定的 RP-Hup DOM。因此三版**共用同一结构骨架**
（`boards-v2/skeleton.html`，含全部既定文案与版面合同），差异轴收窄为：
**色彩体系 / 明暗性格 / 材质与描边语言 / 圆角半径 / 阴影深度 / 字体气质应用 / 氛围母题 / 动效性格**。
三个 subagent 复制骨架后只允许：填 CSS 变量、写方向定制 CSS（纹理/光效/装饰母题）、
改板面顶部信息条与色板/样张的标注文字。禁止改动骨架结构与聊天文案。

## 7. 可读性硬底线（任何风格不豁免）

正文 ≥14px、标签 ≥12px、正文对比度 ≥4.5:1（亮暗两模式分别达标）；留白是构图不是缺席；
装饰 icon 禁 emoji；描边宽度同一层级一致；触控目标示意 ≥44px。

## 9. 五问（开工前已答）

1. 叙事角色：主题方向板 = 决策依据，信息优先、氛围为证；
2. 观众距离：1m 桌面屏幕审阅（板面），但板内手机屏按 10cm 手机视觉还原；
3. 视觉温度：由各方向自答（在板面注明）；
4. 容量：1600×1200 内按合同分区，已留余量；
5. 视觉母题：各方向自答——必须从「雨夜、伞、便利店、热可可、故事续写」这组**本项目内容**里
   取一个别的主题不会有的元素作为母题，写进「form 来自内容的哪里」。
