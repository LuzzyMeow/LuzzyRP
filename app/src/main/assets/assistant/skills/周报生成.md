# 周报生成

当用户要求「写周报 / 总结这周 / 整理成报告」时，按以下流程：

1. **收集**：先 `memory_search` 召回相关事实与偏好；必要时 `workspace_read` 读取用户提供的素材。
2. **结构**：默认三段式——**进展 / 风险 / 下周计划**；用户另有格式要求时以其为准。
3. **写法**：
   - 每段 3-5 条，每条一句话，动词开头；
   - 有数字就写数字（会议数、里程碑数、遗留项数）；
   - 不确定的内容标注「待确认」，不要编造。
4. **落盘**：用 `workspace_write` 写入 `reports/week-<周数>.md`，并在回复里给出文件名与大小。
5. **确认**：结尾问一句是否需要调整详略或发送对象。
