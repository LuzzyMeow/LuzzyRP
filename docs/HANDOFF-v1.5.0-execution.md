5 · 助手模块的既定技术决策（已拍板，不要再问）
================================================================
- 宿主形态：同 Activity 原生覆盖层（ComposeView 懒创建，WebView 保持存活）。

- MCP：先 JSON 导入 + HTTP/Streamable-HTTP/SSE；stdio（npx 类）待沙盒有 Node 后再支持。
- 记忆：走 OpenAI 兼容 /embeddings 接口 + 本地向量检索（纯 Kotlin 余弦，不引端上模型）；
  无嵌入模型时全文注入。
- 与 Web 端关系：只读复用供应商/Key 配置；助手数据（会话/记忆）独立存储；
  不自动同步到 RP 会话。
- 后台/定时任务：本版不做（长任务仅页面前台）。
- 数据模型：Room 10 表 + DataStore + 每助手工作区目录（见计划 §4）。
- 待你按计划 §15 的 D2-D8 建议执行（单模块包隔离 / 随包内置 Alpine / 纯 Kotlin 余弦 /

6 · 已知坑（本项目实踩，别再踩）
================================================================
- git apply 在仓库内按「仓库根」解析路径：验证/重放脚本要在**仓库外**目录执行，
  或用 --directory=<仓库相对路径> 从仓库根执行。
- PowerShell $ErrorActionPreference='Stop' 下原生命令 stderr 会中断脚本：
  调 git 前临时置 'Continue' 并把 stderr 落盘。
- index.html 是 CRLF 为主的混行文件：编辑后核对 git diff --numstat 是否出现整文件伪 diff；
  实体生成须 --ignore-cr-at-eol，应用须 --ignore-whitespace。
- 实体段必须先于字符串块段重放；前像判定用实体头 index <pre> 的 LF 归一 blob id。
- 改 assets 无需手动 bump（assetSignature 自动触发重解压）。
- 上游 app.js 本次把 importCharacterData / selectCharacter 改成选项对象签名：
  调用点不逐个核对会**运行期才炸**（不是编译期）。
- 真机 = 小米 df97f3c4（com.luzzymeow.luzzyrp.debug 是用户日常包，含真实数据）：
  验证用 debug 包 install -r，勿另装 release 包。
