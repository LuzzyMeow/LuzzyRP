> 上游基线 RP-Hub **1.9.2**（`d2f2625`）· versionCode 12 · 稳定版（附 APK 单包）

### 下载

- **`app-release.apk`**（约 17.3 MB，签名 `CN=LuzzyRP`）——**本版起只发布一个 APK 包**。
  此前各版附的「三件套」在本应用里其实是同一份文件：LuzzyRP 是纯 WebView 壳、不含 native
  库，ABI 拆分产出的 arm64-v8a / x86_64 / universal 三个包**字节完全相同**（v1.2.2~v1.4.0
  release 资产 SHA256 实测一致），拆分为零收益。故自 v1.4.0 起关闭 ABI 拆分、只发单包。

### ⚠️ 从测试包（debug）换到正式包：数据不互通，需重新填写一次

**先说声抱歉**——如果你此前一直装的是测试包（`com.luzzymeow.luzzyrp.debug`），换成正式包
（`com.luzzymeow.luzzyrp`）后，**安卓会把两者当成两个独立应用**：正式包读不到测试包里的数据，
所以需要重新填一次**用户信息**（昵称 / 人设等）和**供应商 API 配置**（API Key / URL / 模型）。

原因不是这次更新弄丢了数据，而是两个包的**应用 ID 不同**，系统层面各自拥有独立的存储目录；
同一包内的覆盖安装（升级）数据照旧保留，只有跨包名切换才会「从零开始」。

**你可以按需选择：**

- 想**保留原有数据**：继续用测试包（同包名覆盖安装，数据不动）；
- 想**用正式包**：装好后重新填一次用户信息与 API 配置即可（角色卡 / 世界书 / 预设这类内容
  可用应用内的**导入导出**功能从旧包搬过来，聊天记录与记忆不随包迁移）。

后续版本会继续沿用同一包名，**再次升级不会再出现这个问题**。
