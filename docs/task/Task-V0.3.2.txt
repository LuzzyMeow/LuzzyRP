具体工作内容：
优化与修复：
1、工具 页
1.1 导入MCP工具时，若用户不点击测试链接，则不知道该工具是否真实可用，只要导入了MCP工具就要自动测试链接，并直接在工具页最外层MCP工具分类下能看到连接成功等提示
1.2 SKILL导入的GitHub URL导入的方式无用，无法点击保存按钮，也无法进一步测试
2、 设置 页
2.1 设置了API与APIkey时仍然无用（检查API设置无用的问题 并优化为自动保存并应用）
2.2 设置页自定义的API的端点URL太长会超出屏幕范围，造成显示bug，此时无论切换至内置端点还是自定义端点都是这样
2.3 内置端点需支持用户自由更改API URL并自动保存应用
3、关于 页
3.1 同2.2 仍然超出屏幕显示范围，未优化
3.2 日志检测范围不全面 仅部分操作生效 如只能检测进入关于页，进入其他页却无法检测。请实行全面日志
4、聊天 页
4.1 当选择左下角切换供应商模型时，弹出的弹窗里，会自动框选右上角的叉，点击其他地方的时候框选消失，且每次弹窗都有这个问题，请优化，不要框选
4.2 聊天页下方的切换供应商、思考深度、全屏、添加附件 的四个icon都太小，和其他icon的大小都不一样，极不美观
4.3 聊天框右侧的全屏icon都没有根据聊天框靠右居中，不美观
4.4 全屏输入时，markdown渲染格式下，换行符不生效检测不到，且同步上下滑动滚动的功能未生效
4.5 标题功能仅生效一级标题，即#XX，而往后的二级 三级..均不生效##X ###X
4.6 新增支持查看会话列表时左滑会话快捷删除，右滑会话快捷分享的功能，做好动画交互
4.7 分享会话时可选MD,JSON,PNG三种分享方式，请一定要仔细做好分享功能。PNG是截取长图，一定要做好渲染。
4.8 分享会话选好分享方式后，支持回到选取的会话的内部预览，且有勾选功能，允许用户自由勾选某几条想要分享的消息，或一键全选和一键全不选，做好这个功能
5、TRPG 页
该页为在线网页游戏，你的上一个工作做好了缓存，可现在有一个问题。该网页打开是要下载更新 是因为网页的作者进行了更新，可现在每次通过我们的app启动该网页都会造成下载更新。请查明原因。我认为是bug
6、角色 页
6.1 当角色卡内置文本非中文、英文 时做好降级处理，当前版本（如韩文）会直接渲染乱码。降级为系统默认字体，避免乱码
6.2 角色卡导入时，世界书确实能导入，但依然无法针对角色自动开启相应的世界书
6.3 角色卡导入世界书时，世界书条目确实存在，可内部配置完全丢失，如是否始终激活，激活顺序，关键词等内部配置
7、用户档案 页
用户档案支持新增新档案，却造成与默认填写的档案冲突，且不支持用户选择启用的档案，也不支持用户删除档案。
我认为当前，切到用户档案页时显示 默认填写的档案 和全部档案，默认填写的档案一旦写了 就仅激活该档案，下面新增的全置灰。只有用户选择不激活默认填写的档案时，新增多个档案，可选激活其中一个。
注意，此默认填写的档案非“默认”，而是你在UI前端做的那个，一打开用户档案  页 顶部的那个填写区域
