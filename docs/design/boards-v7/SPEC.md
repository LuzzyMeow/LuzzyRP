## 设计真源约束（任何方向不得违反）

- **零新色相**：色值只取 `DESIGN-compose.md` §2（HCT seed `#CC785C` 生成值）。板上出现的
  渐变第二色为**同色相 T 阶近似**，实现时由 `LuzzyTheme` 色板生成器产出并回填 §2 快照。
- **字体**：Lora 只上区块标题/名牌（品牌不变量）；正文 PuHuiTi / AlibabaSans（板上以系统字体回退）。
- **动效令牌**：进入 200ms / 退出 140ms / ease-out（板为静帧，动效在实施节落档）。
- **触控 ≥44dp**；亮暗双套（板先亮色，实现亮暗都做）。
- **行为不动**：`SettingsData` 注入、文风过滤真开关（默认开）、字号滑杆（12–20px 实时预览松手落盘）、
  SAF 导入导出、迁移报告 Dialog——只动形态，不动逻辑与数据接线。
- **反 slop**：禁紫渐变 / emoji 图标 / 左彩边圆角卡 / 装饰 icon 滥用；空白是构图不是缺席。
