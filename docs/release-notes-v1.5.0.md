## LuzzyRP v1.5.0 — 回退 WebView 手机端 · 上游同步至 1.9.8 · 流式与缓存治理

> 上游基线 RP-Hub **1.9.8**（`53a8d80`）· versionCode 18 · 稳定版（附 APK）

### 本版最重要的事：路线回到 WebView，上游同步能力复活

v2.0 的原生 Kotlin 聊天传输层与 v3.0 的 Jetpack Compose 界面（含 Room 数据层与数据迁移）
**整体删除**，项目回到「原生 Kotlin 壳 + WebView 承载上游 RP-Hub + 扩展层」形态。

动因：原生界面要与上游 Vue 功能长期对齐，等于把上游每次更新翻译两遍；WebView 路线直接复用
上游实现，**同步一次即全量到手**。放弃的代价（原生界面的自绘自由）换来同步能力，这笔账划算。

**上游同步已从 1.9.3 推进到 1.9.8**——分期合并五步全部完成，每步独立验证与回滚：

### 新增

**扩展层「开卷」开屏 + 主题首帧防闪（patch 018 / 027）**
- 品牌级启动动画（掀封 / 纸落 / 界格 / 钤印 / 落墨 / 荧光划线，≈2.3s 定格）；仅用
  transform / opacity，`reduced-motion` 下直出终帧
- 主题快照在**首帧**生效，暗色不再闪蓝

**流式增量渲染旁路（patch 042 / 044 / 045）**
- `v-lsp-stream` 指令按「稳定前缀 + 活动尾部」增量渲染，每次推进前缀都先证明
  「全文 HTML === 前缀 HTML + 尾部 HTML」才提交
- 正文与思考**双活通道**：流式期间不再每 tick 写响应式状态，改由带外通道直上屏
- **不丢任何前端部分**——渲染仍走应用自己的 `renderMarkdown`，显示过滤 / 显示正则 / marked /
  DOMPurify 全保留；真机实测消掉了单次根重渲染 230–340ms 的瓶颈

**KV / prompt 前缀缓存治理（patch 047 / 048）**
- 请求形态改为「纯追加」：实测 6 轮平均公共前缀由 0.9101 提升到接近 1.0
- Anthropic 协议补显式 `cache_control` 断点（该协议无自动前缀缓存，不声明就零收益）

**聊天输入解耦（patch 046）**
- 打字不再触发整屏重渲染（原每键 ≈260–300ms 阻塞）；发送键即时可用，拼字内容不被重渲染冲掉

**多模型商混用 + 供应商三协议（patch 012 / 015）**
- 模型引用体系 `providerId::bareId`，任意数量用户商；主聊天 / 识图 / UI 模板 / 记忆总结 /
  记忆嵌入全部接入
- 供应商支持 OpenAI / Anthropic / Gemini 三协议，编辑器内含模型增删改（显示名 / 上下文长度 /
  最大输出 / 输入模态 / 类型 / 自定义请求体）、五组热检测预设、自定义生图模型接入生图流

**关于页（patch 014 / 024 / 039）**
- CHANGELOG 版本分类下拉 + 关键词检索 + 命中高亮；回到顶部 FAB（滚动 >240px 出现）

**用量趋势图（patch 025）**
- 日 / 周 / 月三粒度 + 供应商 / 模型多色折线 + 单系列 Top8 溢出合并

- **发送键热区漂移**（patch 033 / 046 附带）：关于页 FAB 隐藏态仍吃点击，与发送键重叠 41×25px
- **合并期间修掉的 5 处真缺陷**：`getCustomApiUrlKey` 被误删（运行期 `ReferenceError`）；
  HTML 注释插进标签属性中间（Vue 编译 `SyntaxError`，整页白屏）；`normalizeApiProviderSettings`
  重复定义；模型列表 label 契约类名丢失（label 宽度归零）；`toggleChatFullscreen` 导出悬空
  （整页白屏）
