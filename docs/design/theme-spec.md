# LuzzyRP 新主题 · 设计 Spec（三方向共同输入）

> 依据 huashu-design 三方向硬门：用户指定「Claude 风格」收窄解释空间，不转移选择权。
> 本 spec 是三个方向的唯一共同输入，三个方向各自独立工作、只看本 spec。

## 产品

- **LuzzyRP**：AI 角色扮演安卓应用（RP-Hub 二创 WebView 壳）
- 核心场景：与 AI 角色长文本对话（沉浸阅读）、角色卡管理、世界书、设置
- 使用环境：手机竖屏为主，夜间使用占比高

## 目标受众与情感基调

- 受众：RP 玩家，习惯夜间沉浸式阅读，对「氛围感」敏感
- 基调：**温暖、人文、克制、沉浸**——Claude 的视觉气质（暖米色底、烤橙 accent、衬线标题感、优雅留白）
- 关键词：warm / editorial / calm / premium / human

## 硬性约束

1. **亮暗双模式**（用户已确认）：新主题必须同时提供亮/暗两套，跟随系统或手动切换
2. **字体锁定**（硬性规定 4 + 用户指定）：中文 AlibabaPuHuiTi-3、拉丁/数字 AlibabaSans（本地打包，禁 CDN）；「系统内置字体=经典」作为字体设置选项
3. **经典主题保留**：原版 RP-Hub 浅色主题作为「经典」选项，新用户默认新主题
4. **技术路线**：tailwind.config 色板改 var() 引用 + 扩展层 CSS 变量切换（data-theme 属性驱动）；经典=原版色值默认变量
5. **上游同步**：所有改动走扩展层或登记 patch，不裸改上游大文件
6. **可读性底线**（huashu-design）：正文 ≥14px、对比度 ≥4.5:1、留白是构图不是内容缺席

## 界面结构（方向板必须覆盖）

方向板模拟手机界面（390×844 竖屏），至少包含：

1. **聊天页**：顶栏（菜单/角色名/全屏/清空）、消息气泡区（用户/AI 双色气泡、思考卡片）、输入区（工具栏：发送图片/自动生图/剧情分支/切换模型 + 输入框/发送按钮）
2. **设置页**：设置卡片（用户设置/生图设置/高级设置区块头）
3. **侧边栏**：聊天/用量统计/记忆系统/UI模板/角色卡管理/在线/高级/设置
4. **色板展示**：亮/暗两套色板条（背景/表面/主色/次色/文字层级）
5. **字体展示**：PuHuiTi-3 字重对比（55-Regular/65-Medium/85-Bold）+ AlibabaSans 拉丁展示

## 动效纪律（open-design + huashu-design）

- 进入 200ms / 退出 140ms / ease-out `cubic-bezier(0.23,1,0.32,1)`
- 禁 scale(0) 起步；按压反馈 80-150ms 内
- 动效=物理学：缓动表达重量与摩擦
- 流式正文永不打字机动画（RP-Hub 原生流式优先）

## 输出要求

- 每个方向 1 个完整 HTML 方向板（单文件，内联 CSS，无外部依赖）
- 用 Playwright 截图（390×844 手机视口，亮/暗各一张）
- 三版布局骨架必须互异（至少一处结构性不同）
- 真实内容（角色名「鹿溪」、示例对话），非 Lorem
