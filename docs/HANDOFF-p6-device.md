## 〇 · 开工前置（每次都要）

- [ ] `adb devices` 出现 `df97f3c4`，且 `adb -s df97f3c4 shell getprop ro.product.model` = `25098PN5AC`
- [ ] 构建：`./gradlew :app:assembleRelease` → 确认 `app/build/outputs/apk/release/` **只有一个** `app-release.apk`
- [ ] **签名核对（硬性门）**：`apksigner verify --print-certs app-release.apk` →
      CN=LuzzyRP 且 SHA-256 = `ed78235d2945d2c075b5b1ce92c3eb8ab23222382007fb87dd7cc3f32a9dffb1`（不变）。
      不一致 = **停止发布**（`keystore.properties` 缺失会回退 debug 签名）
- [ ] 装包：`adb -s df97f3c4 install -r app/build/outputs/apk/release/app-release.apk`
- [ ] **launcher 切换核对（P6 后不再需要 am start）**：直接点桌面图标启动，前台应为 Compose 界面；
      双确认：`adb -s df97f3c4 shell dumpsys activity activities | findstr topResumedActivity`
      （P6 前「点图标进 WebView 老界面」就是 launcher 没切的根因）
