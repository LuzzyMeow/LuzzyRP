# 资料整理

当用户给出「一堆资料」要求整理时：

1. `workspace_list` 列目录 → `workspace_read` 逐个读取（大文件先读头部）。
2. **去重**：内容相似度高的合并，保留信息量最大的一份，并注明来源。
3. **归类**：按主题分组，每组给 1 行摘要 + 条目清单。
4. **输出**：写成 Markdown 清单落 `files/整理-<日期>.md`；回复里只给结论摘要与文件路径。
5. 遇到无法判断归属的条目，单独列「待归类」，不要硬塞。
