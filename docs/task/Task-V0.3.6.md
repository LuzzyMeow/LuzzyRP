4.2 翻译设置内，语言按钮的长度不一（比如 日本語 很短，而 Português 和 العربية 很长），却强行塞进固定列宽的 grid（栅格）布局中，导致“气泡”的视觉大小参差不齐、边缘参差不齐。这不仅是视觉上的“不一致”，在移动端上也会因为文字过长而换行，破坏按钮的整齐度。要解决这个问题，可以将网格布局（grid）改为弹性换行（flex-wrap），并把所有按钮统一成圆角药丸（胶囊）形状，让宽度自适应文本长度。目前的布局里，自定义 和其他语言挤在一起。为了让它更清晰，可以把它单独处理：· 在其他语言气泡的最后，加上一个专门的 “+ 自定义” 的按钮。· 点击后，弹出一个 Input 让用户自由输入语言名称（如 "French (France)"）。

5.全局
5.1 优化：当手机切回桌面或其他应用，再切回app时，会出现全屏白屏。只有点击或滑动，才能正常显示app页面
5.2 侧边菜单栏的LUZZY放太高了，会与手机顶部系统原生的状态栏冲突，导致ui不美观
5.3 关于页中的LOGO用错了，你用了别的应用的logo而非本项目的logo图标，指的是安装时手机显示的安装包的那个logo图标
5.4 在设置页，“添加模型”的弹窗中，底部两个核心的操作按钮（黑色“保存”、白色“取消”）被弹出的 Android 虚拟键盘完全或部分遮挡。· 视觉上：按钮底部超出屏幕的可视边界，或者刚好顶在键盘的上边缘，看起来像被“切断”了。· 交互上：用户在填完所有输入框后，必须先把键盘收起来，才能看到并点击底部的“保存”或“取消”按钮。这打断了用户的输入流程，交互体验非常糟糕。导致这个问题的原因是弹窗布局没有针对键盘弹起做动态适配。（由此扩展：检查所有的可唤起输入法的弹窗逻辑）
