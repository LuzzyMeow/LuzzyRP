### ⚠️ 升级须知（请先读）

- **同包名覆盖安装（v2.x → v3.0.0）数据自动迁移**：首次启动会在后台把旧 WebView
  IndexedDB 里的数据（角色 / 会话 / 记忆 / 世界书 / 预设 / 用量）一次性搬进新数据库。
  迁移对旧数据**只读**；失败不写完成标记、下次启动自动重试；迁移报告在
  **设置 → 数据 → 迁移报告**。
- **debug 测试包与正式包是两个应用 ID，数据不互通**（v1.4.0 起的老话术，仍然成立）：
  跨包名切换需重新填写用户信息与供应商配置；同包名升级（本次）数据保留。
- **供应商 / 模型配置入口**：在聊天页输入岛的「模型」面板配置；设置页 API 连接卡
  显示当前状态与引导文案。

### 全新 Compose 界面（P0-P5 摘要）

- **设计语言「织机 Loom」**：HCT 动态色板（珊瑚陶土 seed）亮暗双 ColorScheme、
  Lora + 阿里巴巴普惠体本地字体、MeshGradient 背景、200/140ms 动效令牌
- **聊天页**：真流式逐字上屏、思考节点入气泡（自动展开/流入/收起、常驻）、
  `‹ n/m ›` 多候选切换、附件（选图 → 压缩 → 随消息进请求）、剧情分支树、
  错误悬浮卡栈、用量/耗时/截断脚注、正文可选中复制
- **Agent Loop 引擎（P5）**：请求 = 状态纯函数、KV/prompt 前缀纯追加
  （缓存命中率真机实测 89%，公共前缀 1.0000）、缓存纪元观测、用量页命中率展示
- **数据层（P4）**：Room 存储（一消息一行）、老数据自动迁移、会话总览页（角色 × 分支）
- **周边页**：角色卡 / 世界书 / 预设（含编辑器）/ 记忆 / 用量 / 设置 / 关于，全部接真实数据

### 新增（P6）

- **launcher 切换**：点图标直达 Compose 界面（此前 P1-P5 期间 launcher 挂在 WebView
  MainActivity 下——「点图标进老界面」的根因消除）
- **设置页接真 + 文风过滤开关**：用户设置 / API 连接 / 高级设置三卡显示真实状态；
  文风过滤三处同源（提示词侧 / 显示 / 落库）、设置页可切、**默认开（照上游）**；
  撤掉三个假开关（使用封面背景 / 沉浸模式 / 显示最新用量——功能本体不存在，不留假按钮）
- **导入导出**（设置 → 数据）：预设 / 世界书 / 角色卡经系统文件选择器导出与导入
- **用户可调字号**（设置 → 高级设置）：12–20px 语义、拖动实时预览、松手落盘
- **迁移报告页**：设置 → 数据 → 迁移报告（12 项计数 + 迁移时间；未迁移显式呈现）
- **CoT 流式一致性**：流式期内联思维链并入思考节点（与收尾同源），不再
  「流式期能看到、结束后消失」

### 移除（P6 · WebView 路径退役）

- 删 `MainActivity`（WebView 主壳）、文件选择 / 下载代理、`assets/rphub/**`
  （20.5 MB 上游资产，38 文件）

  老用户升级仍自动迁移
