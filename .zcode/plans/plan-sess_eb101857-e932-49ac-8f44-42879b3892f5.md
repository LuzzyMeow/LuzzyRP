## 5. 领域模型层（P1）
- `UIMessage(role, parts)`，parts：`Text` / `Reasoning(thinking, signature, durationMs)` / `Tool(toolCallId, toolName, input, output, approvalState)` / `Image`；`MessageChunk(id, model, choices, usage)`；`handleMessageChunk` 合并代数：文本增量追加至末 Text part、工具调用按 toolCallId 字符串拼接增量、Reasoning 合并、finishReason 收口。
- `Conversation`（节点树 + 当前分支指针）、`MessageNode(parentId, selectIndex, messages)` 支持分支重roll。
- `CharacterCard`：SillyTavern v2/v3 全字段（name/description/personality/scenario/first_mes/alt_greetings/system_prompt/post_history_instructions/creator_notes/tags/creator/character_version/nonce）+ 本地扩展（worldbookId、regexIds、uiTemplateId、背景图/透明度、来源 builtin/imported/created、readonly）。
- `WorldbookEntry(strategy, keys, keysSecondary, content, position, depth, order, probability, constant, recursion, useRegex, enabled, vectorIndexed)`；`RegexScript(name, find, replace, scopes[user/ai/reasoning/worldbook], timing[display/send/receive×2], minDepth, maxDepth, enabled)`；`MemoryItem(content, category, helpful, harmful, neutral, active, embedding, timestamps)`；`SummaryItem(level A/B/C, roundIndex, content, embedding)`；`ToolApprovalState` 五状态（Auto/Pending/Approved/Denied/Answered）。
- `:core:common`：`Call.await()`（suspendCancellableCoroutine）、JSON 单例（字段序稳定）、`PngTextChunkReader/Writer`（tEXt chunk 手写 CRC32 解析与写入，支撑 chara 导入+导出）。

## 6. AI 层（P2）——真流式 6 不变性落点
```kotlin
interface Provider<T : ProviderSetting> {
    suspend fun listModels(setting: T): List<Model>
    suspend fun generateText(setting: T, messages: List<UIMessage>, params: TextGenerationParams): MessageChunk
    fun streamText(setting: T, messages: List<UIMessage>, params: TextGenerationParams): Flow<MessageChunk>
    suspend fun generateEmbedding(setting: T, texts: List<String>): List<FloatArray>
}
```
- 流式实现（移植 rikkahub `ChatCompletionsAPI`，文件头 `[INVARIANT-STREAMING]` 注释块：禁止改为伪打字/节流/批量 flush）：`callbackFlow` + `EventSources.createFactory(client).newEventSource()` + `onEvent → trySend`（逐 event 零节流）+ `awaitClose { eventSource.cancel() }`；OkHttpClient `readTimeout = 10 MINUTES`（DI 集中定义），SSE 建立后取消 call timeout；上游 `MutableStateFlow<Conversation>` 1 字 = 1 次更新，UI `collectAsStateWithLifecycle()`。
- 三协议：OpenAI 兼容（一等公民，覆盖 GLM/DeepSeek/方舟/OpenRouter）、Anthropic、Google。`ProviderManager` 注册与路由。
- **文本标签兜底** `TagToolCallParser`：流式增量扫描 `<tool_calls>` 开标签后正文进入 pending 缓冲（防 JSON 闪现正文），闭合后解析为 Tool parts；行式 `tool_name:{json}` 与 JSON 数组两种格式；截断容错（maxTokens 截断时尽力解析）；无原生 FC 模型（GLM-5.2 等）自动启用。
- 内置供应商档案：DeepSeek（api.deepseek.com，deepseek-v4-pro/flash，body reasoning_effort=max）、火山方舟 CodingPlan（coding v3，glm-5.2 1024K/128K、deepseek-v4-pro、doubao-embedding-vision，body thinking.enabled）、自定义 OpenAI 兼容；全部可编辑。
- KV 守护：消息序列化稳定化（固定字段序、紧凑 JSON、时间戳不进前缀）+ `KvPrefixStabilityGoldenTest`。

## 8. 生成管线（P4）——Agentic 6 不变性落点
- `ChatService`：生成任务唯一所有者；每会话 `MutableStateFlow<Conversation>` 单一真源；`sendMessage / regenerateAtNode / stopGenerating / handleToolApproval`；任务跑在 appScope（离页不中断，后台通知）；errors StateFlow。
- `GenerationHandler.generateText`（文件头 `[INVARIANT-AGENTIC]`）：`for (step in 0 until 256)`；每步流式生成（逐字 emit）→ 收集末消息未执行 Tool parts → **三 break**：无未执行工具 / 出现 Pending 等审批 / 无可执行工具；执行工具 → **原地回填** `tool.copy(output=...)`（绝不新建 TOOL 消息）；Denied 回填拒绝原因；CancellationException 重抛（Stop 生效）；**禁 tool_choice=required**；被动工具（记忆召回/世界书召回）经系统提示注入，不进 tools 参数、不预执行。
- `ToolApprovalState` 五状态机续跑：审批 UI 写回状态 → 取消旧任务 → 无 Pending 后重入循环。
- **RP 两阶段闭环（maxLoops = 3）**：外层循环 ≤3 轮，每轮 = 阶段一「推理 + 工具规划」（流入思考卡片，工具调用执行并原地回填）→ 阶段二「基于结果生成最终回复」（流入正文气泡）；阶段二消息序列 = 阶段一前缀 + 阶段一 assistant 消息（前缀逐字节一致，保 KV 命中）；阶段一未产生任何工具调用 → 提前收口（break）。**内置提示词强化**：Agentic 协议段注入系统提示，硬性要求每模式 >2 轮思考、>1 次主动工具调用（除被动工具外），不依赖 tool_choice。
- 系统提示组装顺序（KV 分层）：稳定前缀〔角色卡 system prompt → NSFW 块（占位）→ 世界书常驻条目 → C 级摘要 → 各工具 systemPrompt()〕→ 半稳定段〔B 级摘要 → 记忆 Top-K 注入〕→ 动态尾段〔A 级摘要 → 裁剪后对话历史 → 本轮输入〕。裁剪器保证不拆散工具调用/结果对。
- **NSFW 占位**：`prompts/NsfwBlock.kt` 独立常量文件留空占位，注释明确「由用户手动填写；禁止任何审查/过滤/改写逻辑触碰此内容」。

## 9. RP 生态（P5）
- **角色卡**：PNG 导入（tEXt `chara` base64 → spec v2/v3 解析器，字段映射表进 PLAN）、JSON 导入、**PNG 导出**（写回 tEXt chunk）、头像 1:1 裁剪（min(w,h) 左上起）、导入自动落位（提示词/开场白/世界书/正则各归其位并自动启用）；内置默认卡「鹿溪」（Task-V0.4.1 附录提示词，readonly 保护）。
- **世界书三策略**：常驻（每轮按 position 注入）；关键词（扫描最近对话 + 递归扫描已注入条目，命中 keys/概率 roll/order 排序）；向量（最近用户输入 + AI 正文切片 → embedding → sqlite-vec Top-K + 相似度阈值）。三策略按 entry 的 strategy 字段共存。
- **正则脚本**：五作用域 × 四时机 × 深度区间，replace 支持 `{{match}}`/$1；内置预设（思维链剥离/引用/旁白/md 代码块/标签清理）。
- **UI 模板**：`LuzzyTemplateEngine`（{{placeholder}} 注册表：时间/日期/角色名/用户名，轻量条件段，无重型依赖）。
- **收藏**：消息/会话收藏页；**会话导出** MD/JSON/PNG 长截图（系统分享面板）。
- **三级摘要**：A 级每轮 ≤50 字（盲续五要素）；B 级每 10 轮合并 ≤10 条；C 级每 50 轮固化永久。生成完成后异步执行不阻塞回复；嵌入写 vec 表。
- **ACE 长期记忆**：Execute（Top-K 注入 + 检索工具）→ Reflect（回复后 LLM 反思本轮记忆有用/有害/无关 → 更新计数）→ Update（提取新事实 → 余弦≥0.92 去重合并 → 新增）；评分淘汰（helpful−harmful + 失活时长，容量可配）；记忆管理页（卡片列表编辑/启停/删除）。
