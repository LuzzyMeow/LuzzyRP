# 代码审查

收到代码审查请求时，按顺序检查并逐条给出**位置 + 问题 + 建议**：

1. **安全**：密钥硬编码、注入（SQL/命令/路径穿越）、越权、日志泄漏敏感信息。
2. **正确性**：边界条件（空值/超长/并发）、错误处理是否吞异常、资源是否释放。
3. **可维护性**：命名、函数长度、重复逻辑、缺失的注释与测试。

输出格式：
- 🔴 必须修（安全 / 正确性） · 🟡 建议修（可维护性）
- 每条给出 `文件:行号` 与最小改法；不改无关代码。
- 最后给一句总体结论（可合并 / 需返工）。
