落笔成序The Preface Stroke

满屏冷调 AI 工具里，LuzzyRP 先递给你纸与墨——一张暖纸留白开场，三处手作记号落定，故事从墨触到纸面的那一秒开始。

设计师视角

原研哉 Kenya Hara（日本设计中心 / MUJI 艺术总监）——「白不是空无，而是容纳一切的器；设计不是填满，而是让意义从留白中自己浮现。」

本板应用：全片自一张空纸开始，只落三处手作记号——钤一枚白狐印、落一道珊瑚墨线、页脚点一个「序」；文字与墨都迟到，让纸先到场。只取其哲学与思维，不取其作品配色，全部颜色来自 LuzzyRP 既有 token。

视觉母题 · 落笔

form 来自笔触纸的第一划：入纸（钤印下压 0.96 → 1.015 → 1，纸面承接重量）→ 摩擦滑行（墨线 scaleX 自左晕开，长缓动收尾 = 墨的摩擦）→ 收笔；层级借书籍扉页排印传统：印 → 字标 → 墨线 → 标语 → 页码。刻意回避「翻开手记 / 墨团铺满」等重母题，守住 2 秒内的呼吸感。
