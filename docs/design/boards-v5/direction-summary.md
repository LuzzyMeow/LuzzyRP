# boards-v5 · 三方向速览（会话总览页）

> 每方向两版**真实渲染**（亮/暗），同一份真实数据、同一套品牌令牌、同一尺寸（390×844 dp @2×）。
> 详细 spec / 取法 / 约束见 [`SPEC.md`](SPEC.md)。**这三个方向等你选，我不替你定。**

## A · 错落拼贴　`direction-a-collage-{light,dark}.png`

- **逻辑**：秒数轮盘（`date +%S`=42 → 42%20+1 = 网页库 **#3**）= 孟菲斯复古拼贴最大化
- **语境内诠释**：品牌令牌/字体不动，只取它的**构图基因**——非均匀网格、模块大小不一、刻意错位与轻微旋转
- **骨架**：卡片大小不一（有的只占 4 列并右移、有的占 5 列靠左）；空会话用**虚线框「未写的页」**并排两块
- **accent 用法**：楼数用 tertiary 色块；当前会话用左侧 2px primary 竖条（共 2 处，符合 `craft/color.md` 上限）
- **降级声明**：孟菲斯的做旧纸质肌理**纯 CSS 无法还原**（原库自述还原度 72%），本稿**不假装做出该质感**
- **它赌的是**：你愿意让「我写过的一堆东西」有**拼贴的松散感**，而不是整齐的列表

## B · 分组行　`direction-b-grouped-{light,dark}.png`

- **逻辑**：现实参照 = **Things 3** 的分组列表（粘性组头 + 统一行高 + 右侧元数据对齐）
- **骨架**：角色=粘性组头（monogram + 名字 + 会话数），分支=等高 68dp 行（左分支名、右条数、下方一行预览）
- **空会话**：灰字斜体「还没开始」，行照样占位
- **accent 用法**：当前会话的分支名转 primary + 行尾小圆点
- **它赌的是**：你最在意**信息效率**——一屏扫完所有会话，像看任务清单一样干脆

## C · 目录页　`direction-c-contents-{light,dark}.png`

- **逻辑**：最佳设计师 = **iA Writer 的 Library**（排版即界面）
- **骨架**：**零卡片、零 chip、零分隔线**——只有一列文本；角色是「章」（Lora + 两位章次 + 疏字距），
  分支是「节」（14px 缩进 + 一条发丝竖线做缩进标记），预览 2 行、比分支名更小更淡
- **空会话**：Lora 斜体「还没有开过口」，缩进层级仍保留
- **accent 用法**：当前会话只有一个**空心小圈**（不用色块、不用徽标）
- **它赌的是**：这一页读起来应该像**书的目录**——凭一句话的余温认出那一段，而不是靠文件名

## 三者的结构性差异（不是换色换字体）

| | A 错落拼贴 | B 分组行 | C 目录页 |
|---|---|---|---|
| 内容单元 | 不等尺寸卡片 | 等高行 + 粘性组头 | 无容器文本段 |
| 层级手段 | 块大小与错位 | 组头 + 发丝线 | 字号 + 缩进 + 留白 |
| 数字表达 | tertiary 色块 | 右对齐裸数字 | 括号式细体数字 |
| 头像 | 30dp 方形 monogram | 22dp 圆形 monogram | **不用头像** |
| 一屏信息量 | 少（约 5 条） | 多（6 条全见） | 中（5 条，含 2 行预览） |
| 与既有七页的关系 | 最跳 | 最一致 | 最有作者感 |

## 我的取舍（**仅供参考，不影响你的选择**）

- 若目标是「和现有七页一致、马上能用」→ **B**：它的骨架与角色卡/世界书页同族，风险最低。
- 若目标是「这一页要有自己的气质，配得上多年的写作」→ **C**：它把「预览是主角」这件事做到了极致，
  且 accent 用量最省，最符合 Loom 的克制。
- **A** 是刻意的冒险：它把「一堆散落的写作」这件事说得最直白，但松散感是双刃——
  重度用户（几十条会话）下错位可能读成凌乱。选它我会在实现时把错位收敛到「只在大卡上」。

## 三条都需要你拍板的细节（选完方向后我一并处理）

1. **入口放哪**：侧栏新增「会话」项（与角色/世界书/预设并列）—— 还是聊天页顶栏加一个入口？
2. **点一行之后**：直接切到该角色该分支（并沿用「记住上次分支」的现有行为），对吗？
3. **预览用哪一条**：现在是「**最后一条**正文」（所以你会看到 `<thinking>` 那个脏前缀）；
   也可以改成「**最后一条用户发言**」——读起来更像目录（「我在哪一年？」）。
