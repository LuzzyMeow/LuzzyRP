# LuzzyRP 主题 / UI / UX / 前端显示效果完全重制计划（v0.3.0 · Design Overhaul）

> 上一轮的缺口如实承认：技能只做了存档与 DESIGN.md 文档，**可见的视觉与动效重制未做**。本轮以 4 项 SKILL 为工作方法本身，逐层重制。目标：界面让人认不出是上一版（huashu-design 的交付标准）。

## Phase 0 — SKILL 深度挖掘（动手前完成，产出设计基线）
1. **ui-ux-pro-max**（检索工具实操）：
   - `search.py "roleplay storytelling chat expressive" --design-system --variance 5 --motion 8 --density 5` 生成移动端设计基线；
   - 逐项检索 `--domain ux`（tap feedback / dialog focus / stagger list）、`--domain style`（expressive/glassmorphism 对比选型）、`--stack jetpack-compose`；
   - 通读 `references/pro-rules.md` + `references/quick-reference.md` §6/§7（暗色对比 + 动效）。
2. **huashu-design**：精读 `animation-best-practices.md`（物理感动效语法）+ `animation-pitfalls.md`（避坑清单）+ `design-styles.md` + `typography.md`，提炼「动效=物理学」规则表（缓动/时长/节奏/层次）。
3. **open-design**：按其契约模式将 DESIGN.md 升级为 **v2 品牌契约**（本文档为唯一真源，所有 UI 改动对照执行）。
4. **awesome-design-md**：参照 claude / linear / notion 三份 DESIGN.md 的 Colors/Typography/Elevation/Motion 章节结构，落 LuzzyRP 专属规格。

## Phase 1 — 主题令牌系统重制（Theme.kt 全面重写）
1. **AuroraColor v2**：完整 Material3 方案（现存仅映射主次色）——补全 surfaceContainer 全族、outline/outlineVariant、inverseSurface/OnSurface、scrim、surfaceTint；亮/暗/AMOLED 三套独立校验（正文对比度 ≥4.5:1）。
2. **极光渐变系统**：AuroraBrush（Pink→Violet 线性渐变）用于发送按钮/主 CTA/激活态芯片/预设选中态；层级背景渐变（画布顶部微渐变）。
3. **Typography v2**：按 DESIGN.md 重排字阶（显示/标题/正文/标签五层微调字重与字距），聊天正文行高优化，代码/引用样式。
4. **Shapes 令牌**：cornerExtraSmall 8 / Small 12 / Medium 16 / Large 20 / Full；气泡异形角统一。
5. **Elevation/图层令牌（LuzzyElevation）**：Layer0 画布 → Layer1 卡片(2dp) → Layer2 输入栏/悬浮(6dp) → Layer3 弹窗/Sheet(12dp+scrim) → Layer4 Toast；每层对应 surfaceContainerX 色阶 + 阴影。
6. **MotionTokens v2（huashu 纪律）**：分类动效——页面转场（spring 滑入¼+fade 300/195）、弹窗（scale 0.92→1 spring 300 / 退出 195 + scrim fade）、BottomSheet（slide up 300）、列表 stagger 20ms 波次、按压（scale 0.98 + 色彩过渡 150ms）、展开/收起（expandVertically 195）；新增 `reducedMotion()` 尊重系统减弱动效。
7. **LuzzyIconSize 令牌**：Inline 16 / Default 20 / Emphasis 24 / Hero 32；全项目替换硬编码 dp。

## Phase 2 — 全局组件库重制（ui/components 全面翻新）
1. **AuroraSurface v2**：按压 scale 0.98（布局不跳动）+ 色彩过渡；渐变描边变体（activated）；统一圆角/elevation 令牌。
2. **AuroraTopBar**（新）：统一顶栏组件——高度 56dp、图标 24dp 语义尺寸、标题排版、操作位规范；全部页面换用。
3. **LuzzyDialog**（新）：统一确认/提示弹窗——scale+fade 进出（300/195）、scrim 45%、正文左对齐、按钮规范；替换全部 AlertDialog 调用点。
4. **LuzzyBottomSheet 规范**：slide up 300 + 拖拽把手；历史/搜索面板换用。
5. **EmptyState**（新）：图标+标题+引导文案（会话空/预设空/世界书空/收藏空统一）。
6. **输入组件**：LuzzyTextField 焦点态渐变描边；Slider/Chip/Switch 统一主题化。

## Phase 3 — 逐页视觉重制（全部页面，含图层设计）
1. **ChatPage（重点）**：
   - 图层 0：聊天背景图正确分层渲染（修复上轮回退的问题——外层 Box 承载背景 AsyncImage(alpha=透明度)，内容 Column 置上）；
   - 气泡重制：用户=极光渐变淡出底、AI=纸面卡（Layer1 阴影+描边）、圆角异形角、引用高亮；
   - 思考卡片：垂直时间线轨（rail+节点圆点三态），展开动画接 MotionTokens v2；
   - 工具卡片：同轨内嵌 + 状态色 + 审批按钮渐变主行动；
   - 输入栏：Layer2 抬升、渐变发送/停止按钮、字段焦点态；
   - 顶栏换 AuroraTopBar。
2. **HomePage**：顶部问候区（时间分段问候+极光渐变标题）；会话卡（角色头像/最后一条消息预览/相对时间/置顶标识）；搜索栏焦点态。
3. **CharactersPage**：海报式卡格（头像大图+名字叠字+来源角标），新建/导入双按钮明示（修复 5.3 图标不可懂——改为文字+图标组合按钮）。
4. **CharacterDetail**：hero 区渐变底+大头像；分区卡片化；保存按钮渐变主行动。
5. **WorldbookPage / PresetsPage / PresetDetail / ProfilePage / MemoryPage**：换 AuroraTopBar + AuroraSurface v2 + EmptyState + 统一芯片/滑条。
6. **Settings 族**：分区卡片化（Layer1）、区块头渐变强调、关于页品牌区。
7. **弹窗与转场全局替换**：确认弹窗换 LuzzyDialog；页面转场换 spring 化 slide+fade；预测式返回保留。
