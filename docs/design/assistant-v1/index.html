DIRECTION C

场记 Slate

左轨导航，右栏时间轴，对话即剧本。

叙事优先：左侧 56dp 常驻图标轨，全部页面 1 跳直达；会话页右侧是章节时间轴（旁注 / 步骤组 / 工具节点），记忆页走编年体。

关键 token 用法
  • 思考卡 = 旁注：2dp hairline 竖线 + Lora 斜体 13.5dp
  • 工具卡 = 时间轴节点卡（coral / warning / error 圆点）+ 等宽参数块
