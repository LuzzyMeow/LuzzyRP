**供应商自定义图标（patch 035）**

**记忆召回思考节点（patch 031）**

- 复用结构化召回标记生态，失败静默降级；纯文本回复（无卡片）不显示

**记忆内容管理器实时联动（patch 036）**
- 面板展开时，向量/总结补录新增分片**即时出现**在列表中（原为打开时快照，不实时更新）

### 性能

**流式渲染降载 + 合成层瘦身（patch 032/034）**
- 流式渲染间隔 60→120ms + 流式期渲染 LRU 旁路（消除全文 O(n²) 重算与缓存驱逐）
- 高频面退实底：气泡 / 输入岛 / 侧栏 backdrop-filter 归零；常驻合成层 40-60 → 按需创建
- 开屏转场去 filter:blur（全屏逐帧重栅格 ≈3510×7800 像素/帧的掉帧主源消除）

**发送键热区根除（patch 033）**
- 输入区过渡定向化（FAB v4 配方）——视觉位置与点击热区完全对齐
