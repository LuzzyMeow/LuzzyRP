## 0. 共同前提（三方向一律遵守，不是差异点）

### 0.1 品牌与 token 冻结

- **唯一设计真源 = 仓库根 `DESIGN.md`**。本文件不新增任何色相、圆角、阴影、字体栈或动效时长；
- 色板只取 `DESIGN.md` Colors 章既有 token（亮/暗两套），差异只允许做**面积、层级、排版尺度、栅格**的组织；
- 字体：display = `Lora`（对位 Copernicus/Tiempos，文学声音）；正文 UI = `AlibabaSans` + `Alibaba PuHuiTi 3.0`；
  代码/终端 = 系统等宽栈（`ui-monospace / Consolas`，无 CDN）；
- 圆角：气泡 16 / 卡片 12 / 输入岛 22 / 按钮 10-12 / pill 999；
- 阴影：亮 `0 2px 8px rgba(20,20,19,.05)` 纸感级；暗以表面色阶 + 发丝线分层，阴影收弱；
- 动效基线：进入 200ms / 退出 140ms / `cubic-bezier(0.23,1,0.32,1)`；起步 `scale(0.96)+opacity:0`，禁 `scale(0)`；
  尊重 `prefers-reduced-motion`（直接呈现，不做 0ms 抖动）；
- 正文 ≥14px、行高 1.55-1.7、caption ≥12px；对比度亮暗分别 ≥4.5:1。

### 0.2 工程红线（v1.3.0 性能档位，三方向都不得违反）

- **高频表面（聊天气泡 / 输入岛 / 列表行 / 工具卡 / 步骤组 / 终端输出）一律实底**，`backdrop-filter: none`、`will-change: auto`；
- 玻璃（磨砂）只允许出现在**低频 chrome**：模态面板、消息操作工具条、以及 `DESIGN.md` 单点授权的**思考卡**（live 态 alpha .96 + blur 6 + coral 描边，结束后恢复全玻璃）；
- **静态初稿的取舍**：三张 mock 一律不启用 `backdrop-filter`——CDP/headless 截图在页面存在激活 blur 时会挂起（`DESIGN.md` 已实测记录），静态稿用「近实底 + 发丝线 + 纸感投影」表达层级即可；实装的思考卡磨砂配方照 `DESIGN.md` 执行；
- 手作记号（荧光笔划 / 伞骨线 / 雨点）**同屏 ≤3 处**，只做情绪注脚；
- 禁：emoji 图标、左彩边圆角卡、紫渐变、均匀深蓝底 + 霓虹 glow、裸 `blue-*`/`indigo-*`/`violet-*` 色相。

### 0.3 三方向的差异维度（同一品牌语言下的三种组织方式）

| 维度 | 允许差异 | 不允许差异 |
|------|---------|-----------|
| 信息架构与导航模型 | 一级导航形态、二级入口深度、页面归属 | 功能是否齐全（八类页面三方向都必须可达） |
| 布局与栅格 | 单列 / 双列 / 轨道 + 内容；边距与留白节奏 | 关键尺寸 token（圆角/触控区） |
| 信息密度 | 单屏条目数、行高、折叠策略 | 正文与 caption 字号下限 |
| 层级表达 | 靠什么承担层级（表面色阶 / 发丝线 / 排版尺度 / 轨道指示） | 阴影配方与色阶本身 |
| 组件形态 | 气泡 / 卡片 / 时间轴节点 / 日志行的形态选择 | 输入岛、发送键、按钮的 token 映射 |
| 动效叙事 | 转场语法、节奏、stagger 策略 | 200/140ms 与缓动曲线 |
| 排版尺度与节奏 | display 字号阶梯、行高节奏 | 字体栈与字体选项 |

### 0.4 共同信息架构素材（来自 `docs/PLAN-v1.5.0-assistant.md`）

八类核心页，三方向都必须可达：**助手列表 / 会话 / 记忆 / 技能 / MCP / 工作区 / 终端 / 设置**。

- 助手：多助手（头像 + 名称 + 最近会话时间 + 未读）；新建 / 复制 / 归档 / 删除（软删 + 二次确认，工作区目录默认保留可勾选一并删除）；
- 会话：按助手过滤、日期分组（今天 / 昨天 / 7 天内 / 本月 / 更早）、日期筛选、FTS4 检索（输入即搜 300ms 防抖 + 命中高亮）、会话操作（重命名 / 归档 / 删除 / 导出 MD·JSON / 置顶）、两种空态；
- 记忆：三模式 `full` / `embed` / `hybrid`（TopK 8、阈值 0.35、混合取最近 5 条），嵌入失败自动降级 `full` 并在 UI 提示；
- 技能：front-matter（name / description / tools）+ 正文注入；内置 / 文件导入 / URL；全局启用 + 助手绑定；同名「用户导入 > 内置」；
- MCP：HTTP(Streamable) / SSE 支持，stdio 预留（P4 依赖沙盒）；JSON 导入两种格式、逐条预览 + 可达性检测；工具命名空间 `mcp__<server>__<tool>`；外部工具首次调用逐个确认；
- 工作区：每助手独立 `files/ attachments/ exports/`；配额 2GB / 单文件 64MB；路径越界拒绝；
- 终端：沙盒（proot）/ 全局（宿主）双模式；PTY + ANSI + Ctrl-C + 退出确认；单次回传上限 200KB；
- 设置：提示词多行编辑器 + 变量菜单（`{{time}} {{date}} {{model}} {{assistant_name}} {{workspace}} {{memory_count}}`）；模型 `providerId::bareId`；参数按能力置灰；请求体扩展 JSON 禁覆盖 `messages/tools/stream`；「预览最终请求」脱敏面板；
- 渲染：Markdown 增量渲染节流 **100ms**；代码块 >20 行折叠；思考卡默认折叠；工具卡执行中展开、结束折叠；连续 ≥3 个工具 + 思考节点聚合「步骤组」；审批弹窗（允许一次 / 本会话始终允许 / 拒绝）；单条 >50KB 降级纯文本。

## 1. 方向 A · 卷宗（Ledger）

**一句话定位：对话是家，工具收进抽屉。**

### 1.1 信息架构

- **一级导航：没有全局导航栏。** 进入助手层即落在「当前助手的会话列表」——导航的「家」是会话，不是功能目录。
- **助手切换 = 顶部横向头像条**（40dp 圆头像 + Lora 名字，选中态 coral 圆环 + `surface-card` 底）；末尾 `+` 进「全部助手」管理页（列表卡 + 新建/复制/归档/删除）。
- **二级入口 = 右侧抽屉**：会话页顶栏 `⋯` → 抽屉（记忆 / 技能 / MCP / 工作区 / 终端 / 设置 六项，纵向 56dp 行 + 当前助手的模型 chip）；抽屉内再进各管理页（`settings-page-header` 惯例 + 返回）。
- 八类页面归属：助手列表（顶栏头像条 → 管理页）· 会话（一级，家）· 记忆 / 技能 / MCP / 工作区 / 终端 / 设置（抽屉二级）。设置页内部按 `提示词与模型 / 参数 / 请求体 / 预览` 四段卡列，与 Web 端「外观→设置→关于置底」的顺序同构。

### 1.2 布局与栅格

- 单列，左右边距 **16dp**；竖向节奏 8 / 12 / 16 / 24 / 32dp（4dp 基准）。
- 会话页三段：顶栏 56dp（Lora 助手名 17dp + 会话标题 13dp muted + ⋯）→ 消息流（`padding-block 12dp`）→ 输入岛 60dp（22dp 圆角，键盘上方 8dp 呼吸）。
- 会话列表行高 **68dp**（两行文本：标题 15dp / 摘要 13dp muted），分组头 32dp（Lora 12dp + 发丝线通栏）。
- 抽屉宽 `min(300dp, 82%)`，行高 56dp，抽屉底部固定「设置」并加发丝线分隔。
- 记忆页卡列：卡内 padding 16dp，卡间距 12dp，检索框 44dp 高（`surface-soft` 底 + hairline）。

### 1.3 信息密度

- 会话列表单屏 **7 条**（含 2 个分组头）；助手头像条单屏 **5 个**；抽屉单屏 **6 行**；记忆卡单屏 **4 条**（含模式条 + 搜索框）。
- 行高节奏：列表 68dp / 抽屉 56dp / 记忆卡自适应（≈96dp）；正文行高 1.65。
- 折叠策略：工具卡默认折叠为一行（工具名 + 状态 pill + 耗时）；步骤组折叠为「N 步 · 总耗时」；思考卡折叠为一行摘要；代码块 >20 行折叠；单条 >50KB 降级纯文本 + 手动展开。

### 1.4 动效叙事

| 事件 | 参数 |
|------|------|
| 会话进入（列表 → 会话） | 内容区右移 12dp + 淡入 **200ms** ease-out；返回时反向 **140ms** |
| 抽屉（二级入口） | 抽屉右滑入 **200ms** ease-out + scrim 200ms 淡入；关闭 **140ms**；scrim 点击即关 |
| 消息进入 | 上移 8dp + 淡入 **200ms**；退出 **140ms** |
| 思考卡 live → 折叠 | live 态 coral 描边淡出 200ms，折叠高度动画 200ms（`grid-template-rows: 0fr→1fr` 同族做法） |
| 工具卡状态 | 等待审批 → 执行中 → 成功：pill 底色与文案交叉淡入 **200ms**，不做位移 |
| 流式渲染 | 文本 / 思考 / 工具进度三通道分渲染，统一 **100ms** 节流增量；reduced-motion 下仍逐字（不逐字反而更闪） |
| 记忆召回节点 | 时间线首位节点淡入 200ms；无卡片回复时不显示（对齐 patch 031 D2 语义） |

### 1.5 组件形态（token 引用）

- **AI 气泡**：`surface-soft` 实底 + `hairline` 1px + 圆角 16dp；名牌 = Lora 13dp `muted`；最大宽度 84%；
- **用户气泡**：`#F1E3D9`（暗 = coral-50 `#2E211B`）实底 + coral-300 / coral 边 + 圆角 16dp；
- **思考卡**：整卡 `surface-card` + hairline，头部 44dp（等宽 11dp「THINKING」+ 时长 + chevron）；live 态 coral 描边（实装按 `DESIGN.md` 换磨砂配方）；
- **工具卡**：单行 52dp——等宽工具名 13dp + 参数摘要 `muted` + 状态 pill（success/warning/error token 底色 12% + 文字色）+ 耗时 12dp；
- **步骤组**：折叠头 56dp「5 步 · 12.4s」+ 展开为缩进步骤行（左 16dp 缩进 + 12dp 圆点，不用彩边）；
- **输入岛**：`surface-card` 实底 + hairline + 圆角 22dp + 纸感投影；左附件图标 44dp 触控区；发送键 = 44dp coral 圆（`#A9583E` / 暗 `#B85C3E`）+ 白字；
- **审批弹窗**：白纸面 + 12dp 圆角 + 主按钮 coral、次按钮 hairline 描边、危险动作 `error #C64545` 文字按钮；
- **记忆卡**：类型 chip（`surface-card` 底 + 12dp caption）+ 正文 15dp/1.65 + 底部 meta 行（来源 / 时间 / 相似度条 4dp 高）。

### 1.6 与另外两个方向的差异点

- vs **B 工作台**：A 无底部 tab、无概览首页；功能藏在抽屉而非平铺成 tab；密度中低、以长读为先；B 用双列栅格与状态卡抢首屏，A 的首屏就是会话流。
- vs **C 场记**：A 无常驻侧轨、无时间轴；层级靠表面色阶与发丝线，C 靠轨道指示与排版尺度；A 的转场是「抽屉横向」，C 是「内容让位于轨道」。

### 1.7 风险与适用场景

- **风险**：二级入口深（记忆/技能/MCP 需 2 跳），发现性弱；抽屉与 Web 端侧栏隐喻重复，用户可能误以为「回到 Web」；功能多的助手（技能 + MCP + 终端都用）会频繁开关抽屉。
- **缓解**：会话页顶栏在无会话时降级为「功能入口条」（三枚 pill：记忆 / 工具 / 工作区）；抽屉支持左滑关闭 + 返回键优先关抽屉。
- **适用**：以对话产出为主的用户（写作、整理、问答）；单手竖屏长读；对「文学阅读感」敏感的用户。

## 2. 方向 B · 工作台（Workbench）

**一句话定位：先看仪表盘，再进对话。**

### 2.1 信息架构

- **一级导航 = 底部 4 tab（56dp）**：会话 / 记忆 / 工具 / 助手。
  - 会话 = 该助手全部会话（日期分组 + 检索）；
  - 记忆 = 记忆条目（类型 chip 过滤 + 搜索）；
  - 工具 = 顶部 Segmented 四段：技能 / MCP / 工作区 / 终端；
  - 助手 = 助手列表 + 新建/复制/归档 + 当前助手设置入口。
- **助手切换 = 底部 tab 之上的顶部当前助手条**（56dp：头像 + Lora 名称 + `providerId::bareId` 模型 chip + 切换 chevron），点击展开全屏切换面板。
- **进入助手 = 概览首页**（Assistant Home，作为「会话」tab 的顶部区块，可上滑收起）：状态卡 4 枚（模型 / 记忆模式 / 技能数 / MCP 连接）+ 「继续上次会话」大按钮 + 最近 3 条会话 + 快捷动作 5 枚。
- 八类页面归属：全部在一级 tab 内 1 跳可达（终端与设置是 tab 内的全屏页），这是三方向里入口最浅的。

### 2.2 布局与栅格

- **双列栅格**：内容区 16dp 边距 + 12dp gutter → 卡片宽 ≈171dp；状态卡 2×2；快捷动作 4 列（每枚 72dp）。
- 三段固定 chrome：顶部助手条 56dp、底部 tab 56dp（+ 安全区）；内容区滚动，底部 `contentPadding` 预留 tab 高度，避免遮挡。
- 卡片圆角 12dp、内 padding 14dp；列表行高 64dp；检索框 44dp；分段控件 36dp（`surface-card` 底 + 选中 `coral-100` / 暗 coral-50）。
- 记忆页：列表行 64dp + 右侧类型 chip；工作区 = 文件树行 48dp + 顶部用量条 6dp。

### 2.3 信息密度

- 概览首页单屏 **≥12 个有内容的信息块**（4 状态卡 + 1 主按钮 + 3 会话行 + 5 快捷）；记忆列表单屏 **8 条**；工具目录单屏 **9 行**；助手列表单屏 **6 张卡**（2 列）。
- 行高最紧：列表 64dp、工具行 52dp、文件树行 48dp；正文行高 1.6（阅读仍达标）。
- 折叠策略：概览区块「状态卡 → 会话 → 快捷」可整体上滑折叠；工具卡 = 日志行，默认单行；步骤组 = 进度条 + 可展开列表；MCP 服务器卡默认收起，展开显示工具清单与 `lastError`。

### 2.4 动效叙事

| 事件 | 参数 |
|------|------|
| 概览卡进入 | **stagger 24ms/张**，单张上移 6dp + 淡入 200ms（总时长 ≤ 260ms） |
| tab 切换 | 旧内容淡出 **140ms** → 新内容淡入 **200ms**（不做整页横滑，避免与底部 tab 指示器争夺动线） |
| Segmented 切换（工具 tab） | 选中底块 200ms 位移 + 内容 140ms 淡出 / 200ms 淡入 |
| 进度 / 用量数字 | 数值与条形 200ms ease-out 收敛；不做无限循环动效 |
| 工具日志行 | 新行自下浮入 200ms；状态点 140ms 变色（等待→执行→完成） |
| 流式渲染 | 同 A（100ms 节流），但思考卡在 B 里默认**收起为进度条**，不逐字展开 |

### 2.5 组件形态（token 引用）

- **卡片是主容器**：`surface-card` + hairline + 12dp 圆角 + 纸感投影（亮 `0 2px 8px rgba(20,20,19,.05)`）；
- **气泡**：与 A 同 token，但最大宽度收到 78%，把宽度让给栅格；
- **工具卡 = 运行日志行**：等宽 12dp 时间戳 `muted-soft` + 工具名 13dp + 状态 pill + 右侧耗时；多行时左侧 2dp 竖线用 `hairline`（不是彩色边）；
- **步骤组 = 进度条 + 列表**：顶部 4dp 进度条（coral，已完成段实色 / 未完成段 `surface-card`）+ 「5 步 · 12.4s」+ 展开列表；
- **状态卡**：大数字用 Lora 22dp（display），标签 12dp caption，副行 12dp `muted`；
- **记忆卡**：行卡 + 类型 chip + 右侧相似度 4dp 竖条；嵌入模式在顶部一条 `surface-soft` 状态带（模式 + TopK + 阈值）；
- **输入岛**：与 A 同 token（22dp / coral 圆键），但底部 tab 存在时整体上移 8dp 与 tab 拉开层级。

### 2.6 与另外两个方向的差异点

- vs **A 卷宗**：B 有概览首页与底部 tab，入口最浅、密度最高、双列栅格；A 无全局导航、单列、抽屉。
- vs **C 场记**：B 靠「栅格 + 状态卡」表达层级，C 靠「轨道 + 排版尺度」；B 的会话是四个 tab 之一，C 的会话是默认主场。

### 2.7 风险与适用场景

- **风险**：仪表盘气质与「暖幕手记」的文学/手账声音冲突，容易滑向通用 AI 控制台；底部 tab + 顶部助手条 + Segmented 三层 chrome 挤压阅读高度；概览首页对「只想继续聊」的用户是多余一步。
- **缓解**：状态卡一律用 Lora display 数字 + 纸感卡（不用彩色图标底）；概览区块可折叠且记忆位置；底部 tab 用发丝线而非投影与内容分层。
- **适用**：把助手当「工作台」的用户（多助手、多工具、跑终端/工作区）；需要一眼掌握记忆与工具状态的重度用户；平板/大屏更合适。

## 3. 方向 C · 场记（Slate）

**一句话定位：左轨导航，右栏时间轴，对话即剧本。**

### 3.1 信息架构

- **一级导航 = 左侧常驻 56dp 图标轨**：助手头像（轨顶）/ 会话 / 记忆 / 工具 / 工作区 / 终端 / 设置。**全部 1 跳直达**，没有抽屉、没有 tab。
- **助手列表 = 轨顶头像点击 → 全屏「演员表」页**：Lora 28dp 大标题 + 助手卡（头像 / 名字 / 最近会话 / 模型 chip / 未读）。
- **会话页 = 轨道 + 内容双栏**：内容区顶部是 Lora 26dp 大标题（会话标题 + 助手名 13dp muted），正文下方右侧有**章节时间轴**（步骤组 / 工具 / 思考节点纵向排列，圆点 + 1.5px 伞骨线）；点节点跳转对应消息。
- **记忆页 = 编年体**：年份/日期用 Lora 20dp 做分隔（「2026 · 九月」），条目按时间倒序，右侧显示相似度与来源。
- 八类页面归属：轨道直达（1 跳），工具相关页在轨道「工具」内用顶部 Segmented 分段（技能 / MCP）。

### 3.2 布局与栅格

- **双栏**：轨道 56dp（固定，`surface-soft` 底 + 右发丝线）+ 内容区 334dp（390dp 屏）；内容左右边距 20dp（比 A/B 更宽，服务大字号长读）。
- 会话页顶部大标题区 96dp（标题 Lora 26dp/1.25 + 副行 13dp + 会话操作图标 3 枚）；正文段落间距 16dp，段落行高 1.7。
- 时间轴宽 40dp（贴在内容区右缘，不占正文宽度），节点 8dp 圆点 + 1.5px 连线；展开时节点卡覆盖式浮出（不挤压正文）。
- 记忆页日期分隔 56dp（Lora 20dp + 发丝线）；条目行高自适应（≈88dp）。

### 3.3 信息密度

- **三方向最低**：会话列表单屏 **5 条**（大行高 84dp：标题 16dp + 摘要 13dp + 时间 12dp）；记忆单屏 **4 条**；轨道单屏 7 枚图标。
- 留白是构图：列表首屏必有 1 个视觉锚点（Lora 大标题 + 最近一条会话的摘要预览卡）。
- 折叠策略：思考卡折叠为「旁注」一行（Lora 斜体 13dp）；工具卡折叠为时间轴上的圆点 + 悬停/点击浮出参数卡；步骤组 = 时间轴的一段（「5 步」标注 + 连接线加粗）。

### 3.4 动效叙事

| 事件 | 参数 |
|------|------|
| 轨道图标切换 | active 底块（coral-100 / 暗 coral-50 圆角 10dp）淡入 **200ms**；图标色 140ms |
| 页面转场 | 内容区自轨道方向右移 16dp + 淡入 **200ms**（方向感由轨道位置决定）；退出 140ms |
| 时间轴节点新增 | 节点自下浮入 200ms + 连线 `stroke-dashoffset` 绘制 200ms；节点呼吸仅 live 态（2s 循环，reduced-motion 停） |
| 工具卡浮出 | 从节点右侧 12dp + `scale(0.96)` + 淡入 **200ms**；关闭 140ms |
| 流式渲染 | 逐字 + 行末呼吸光标；100ms 节流；思考内容在「旁注」位置以 Lora 斜体逐字出现 |
| 返回 | 内容区左移 16dp + 淡出 **140ms**（方向与进入相反） |

### 3.5 组件形态（token 引用）

- **AI 气泡**：`surface-soft` 实底 + hairline + 16dp 圆角，但**名牌升级**为 Lora 15dp `body`（剧作角色名感），气泡最大宽度 88%；
- **用户气泡**：同 A token，圆角 16dp，右对齐；
- **思考卡 = 旁注**：无边框，左侧 2dp `hairline-strong` 竖线 + Lora 斜体 13dp `muted`，折叠为一行「旁注 · 12s」；
- **工具卡 = 时间轴节点卡**：节点圆点（coral 实心 = 成功 / `warning` = 等待 / `error` = 失败）+ 浮出卡（等宽参数块 `surface-card` 底 + 12dp 圆角）；
- **步骤组 = 时间轴段**：连线加粗为 2px + 「5 步 · 12.4s」Lora 13dp 标注，展开时节点卡依次展开；
- **输入岛**：`surface-card` 实底 + hairline + 22dp 圆角 + coral 圆键；底部多一条 12dp 状态线（当前助手 · 模型 · 记忆模式），用 `muted-soft` 文字而非装饰条；
- **记忆卡 = 编年条目**：日期 Lora 20dp + 内容 15dp/1.7 + meta 行（类型 / 来源 / 相似度），条目前置 6dp coral 圆点（仅「本次召回」标记，不做彩边）。

### 3.6 与另外两个方向的差异点

- vs **A 卷宗**：C 有常驻轨道（A 没有），二级深度最浅（全 1 跳）但内容区最窄（334dp）；A 用表面色阶分层，C 用轨道 + 排版尺度分层。
- vs **B 工作台**：C 密度最低、排版尺度最大（Lora 26dp 标题）、会话是默认主场；B 密度最高、会话是四分之一屏。

### 3.7 风险与适用场景

- **风险**：56dp 轨道吃掉 14% 宽度，正文每行约 19 字（15dp/1.7），360dp 小屏需把轨道收成 48dp 或可折叠；时间轴在长会话里会成为滚动负担（需虚拟化 + 只显示最近 12 个节点）；与上游 RP-Hub 侧栏的「左轨」隐喻重复，要避免视觉撞车（轨道用图标 + 文字 tooltip，不用与侧栏相同的圆角块）。
- **缓解**：轨道支持双指/长按折叠为 44dp 图标条；时间轴默认只显示步骤组节点，工具节点展开后出现。
- **适用**：单助手深度使用、长会话复盘、看重「过程可见」的用户；平板横屏可把轨道扩为 88dp 带文字标签。
